# v0.2 계획서 - UI 개편 및 자동 페르소나 생성

## 배경
v0.1에서 유저 피드백:
- 좌측 SETTINGS와 가운데 프롬프트 유형의 차이가 불명확
- 1~5차 프롬프트마다 결과 형식이 있어서 어디를 수정해야 할지 모름
- 프롬프트 엔지니어링 파일 분석, 개선된 프롬프트 출력 등 새로운 분석 모드 필요
- 유저가 문서 유형을 에이전트에게 미리 알려주고 싶음

## v0.1 태그 정보
- Tag: `v0.1`
- Installer: `releases/v0.1/AI_Orchestration_v0.1_Setup.exe`
- Branch: `feature-windows`

## 변경 계획

### 1. 좌측 패널 UI 개편 (`session_setup_panel.dart`)

**현재 구조:**
```
계획서 업로드
ORCHESTRATION (프리셋, 분석 Agent, 검토 Agent)
SETTINGS (실행목적, 비판강도, 리스크포커스, 결과형식)
[시작 버튼]
```

**변경 후 구조:**
```
계획서 업로드

분석 모드 선택 (라디오 버튼)
  ○ 코드/기술 분석
  ○ 기획/전략 분석  
  ○ 경영진 피드백 분석
  ○ 프롬프트 엔지니어링 개선
  ○ 직접 설정

분석 Agent: [드롭다운]    ← 항상 노출
검토 Agent: [드롭다운]    ← 항상 노출
비판 강도: [드롭다운]     ← 항상 노출

내가 원하는 결과 요청 (텍스트 필드)
  "예: 체크리스트 형태로 정리해주세요"

▶ 고급 설정 (아코디언, 기본 접힘)
  프리셋 (3/5/7단계)
  실행 목적
  리스크 포커스
  결과 형식

[오케스트레이션 시작]
```

**수정 파일:** `app/lib/features/session_setup/session_setup_panel.dart`

**세부 작업:**
- [ ] 분석 모드 라디오 버튼 UI 추가
- [ ] Agent 선택 + 비판 강도를 상단으로 이동
- [ ] "내가 원하는 결과 요청" 텍스트 필드 추가
- [ ] 나머지 설정을 아코디언(ExpansionTile)으로 접기
- [ ] 분석 모드 선택 시 실행목적/비판강도/리스크포커스 자동 설정

### 2. SessionState에 새 필드 추가 (`session_providers.dart`)

```dart
// 새로 추가되는 필드
String analysisMode;       // 'code' | 'planning' | 'executive' | 'prompt_eng' | 'custom'
String userResultRequest;  // 유저가 원하는 결과 요청 텍스트
String? autoPersona;       // AI가 자동 생성한 페르소나
List<String>? autoFocusPoints;  // AI가 자동 생성한 단계별 집중 포인트
```

**수정 파일:** `app/lib/providers/session_providers.dart`

### 3. 설정 자동분석 확장 (`session_config.dart` + `thread_providers.dart`)

**현재 자동분석이 결정하는 것:**
- 실행목적
- 비판강도
- 리스크포커스
- 결과형식

**추가로 결정할 것:**
- 페르소나 (예: "당신은 10년차 모바일 UX 전략가이며, 감정 기반 서비스의 리텐션 구조에 전문성이 있습니다")
- 문서 핵심 분석 포인트 3~5개
- 각 단계(1~5차)에서 특별히 집중할 관점

**자동분석 프롬프트 확장:**
```
현재 프롬프트에 추가:
- 이 문서를 가장 잘 분석할 수 있는 전문가의 페르소나를 작성하세요
- 이 문서의 핵심 분석 포인트 3~5개를 도출하세요
- 각 분석 단계에서 집중해야 할 관점을 제시하세요

분석 모드: {{ANALYSIS_MODE}}
사용자 추가 요청: {{USER_RESULT_REQUEST}}
```

**수정 파일:** 
- `app/lib/core/models/session_config.dart` (buildAutoSettingsPrompt 확장)
- `app/lib/providers/thread_providers.dart` (자동분석 결과 파싱/저장)

### 4. 프롬프트 템플릿에 페르소나/집중포인트/유저요청 주입

**현재 템플릿 변수:**
```
{{SOURCE_DOCUMENT_PATH}}, {{PROVIDER_NAME}}, {{RUN_OBJECTIVE}}, 
{{CRITICISM_LEVEL}}, {{RISK_FOCUS}}, {{OUTPUT_FORMAT}}, {{SESSION_CREATED_AT}}
```

**추가 변수:**
```
{{PERSONA}}              - AI가 생성한 페르소나
{{FOCUS_POINTS}}         - 이 단계의 집중 포인트
{{USER_RESULT_REQUEST}}  - 유저가 원하는 결과 요청
{{ANALYSIS_MODE}}        - 분석 모드명
```

**수정 파일:**
- `app/lib/core/services/template_renderer_service.dart` (변수 주입 추가)
- `app/lib/core/services/session_builder_service.dart` (빌드 시 변수 전달)
- `user_handoff_kit/templates/*.md` (템플릿에 변수 위치 추가)
- `user_handoff_kit/templates_custom/*.md` (동일)

### 5. 프롬프트 엔지니어링 모드용 템플릿 세트 추가

**새 폴더:** `user_handoff_kit/templates_prompt_eng/`

각 단계의 역할 재정의:
| 단계 | 기존 (기획 분석) | 프롬프트 엔지니어링 모드 |
|------|----------------|---------------------|
| 1차 분석 | 문서 구조/논리 분석 | 프롬프트 구조/의도/타겟 모델 분석 |
| 1차 비판 | 논리 허점/리스크 검토 | 모호한 지시, 할루시네이션 위험, 누락 조건 검토 |
| 분석 보강 | 보완된 실행 계획 | 구체화된 프롬프트 개선안 초안 |
| 2차 비판 | 최종 검증 | 개선안 엣지케이스/누락 검증 |
| 최종 종합 | 실행 계획서 | **최종 개선 프롬프트 전문 + before/after + 변경 근거** |

**새 파일:**
- `user_handoff_kit/templates_prompt_eng/analysis_prompt.md`
- `user_handoff_kit/templates_prompt_eng/critical_review_prompt.md`
- `user_handoff_kit/templates_prompt_eng/reinforced_analysis_prompt.md`
- `user_handoff_kit/templates_prompt_eng/second_review_prompt.md`
- `user_handoff_kit/templates_prompt_eng/final_plan_prompt.md`

### 6. 가운데 패널 (Stage Editor) 변경

**변경 사항:**
- 프롬프트 유형 드롭다운을 분석 모드와 연동 (자동 설정)
- 프롬프트 편집 영역을 "고급 편집" 토글로 기본 숨김
- 읽기 전용으로 현재 적용될 프롬프트 미리보기만 표시

**수정 파일:** `app/lib/features/stage_editor/stage_card.dart`

## 구현 순서

### Phase 1: 데이터 모델 & 백엔드
1. SessionState에 새 필드 추가
2. session_config.dart 자동분석 프롬프트 확장
3. template_renderer_service.dart 새 변수 주입

### Phase 3: UI
7. session_setup_panel.dart 좌측 패널 개편
8. stage_card.dart 가운데 패널 조정

### Phase 4: 통합 & 테스트
9. 자동분석에서 페르소나/집중포인트 생성 → 프롬프트 주입 연결
